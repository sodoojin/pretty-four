# 이쁜네살 — 출시 준비 & 마케팅 대응 로드맵

> 마케팅 전략(맘카페 1순위 → 인스타 → 콘텐츠 SEO, 신뢰·발달단계 타겟팅·리텐션)에 맞춰
> **지금 부족한 기능**과 **앞으로 해야 할 일(계정·인프라·법무 포함)**을 정리한 문서.
> 작성 기준: 2026-06. 현재 코드 상태에서 실측한 사실 기반.

## 1. 기능 갭 — 마케팅 전략 대응

전략이 요구하는 것(신뢰 / 발달단계 타겟팅 / 빠른 리텐션 / 후기·바이럴 / 광고 반응 측정)에 매핑.

### P0 — 출시/마케팅 시작 전 반드시 (없으면 막힘)

- [ ] **운영 인프라 프로덕션화** — 퀵터널은 URL이 매번 바뀌어 실사용 불가. 고정 도메인 + 상시 서버(맥미니 named tunnel 또는 클라우드) + HTTPS + 프로덕션 DB(마이그레이션, `synchronize:false`) + 시크릿 관리. *(마케팅으로 사람을 불러도 서버가 없으면 전부 이탈)*
- [ ] **Sign in with Apple 추가** — Google/Kakao 같은 제3자 로그인을 제공하면 Apple 심사 가이드라인 4.8상 **Apple 로그인 필수**. 미추가 시 리젝.
- [ ] **계정·데이터 삭제(인앱)** — 회원가입 있는 앱은 앱 내 계정 삭제 제공 의무(5.1.1(v)). 음성·아동 데이터라 더 민감.
- [ ] **AI 비용 통제** — Whisper/Claude는 분석당 과금. 무료 무제한이면 마케팅 유입 = 비용 폭발. 사용자별 한도/요금제 게이트 필요(아래 수익화와 연결).
- [ ] **애널리틱스 도입** — 전략의 "메타 소액광고·인플루언서 반응 테스트"는 **측정 없이는 불가능**. 가입→프로필→첫 분석→재방문 퍼널, 채널별 유입, 리텐션 코호트. (Firebase/Amplitude 등)

### P1 — 마케팅 효과·리텐션 직결 (초기 성장의 핵심)

- [ ] **푸시 알림 (발달단계별)** — 전략이 명시한 "발달단계별 푸시로 리텐션"의 핵심. 아이 월령 기반 단계 팁/리마인드. (APNs key + FCM)
- [ ] **결과 공유 카드** — 맘카페 후기형 바이럴·인스타 확산의 연료. 코칭 결과를 이미지 카드로 공유(개인정보 제외). "내 아이가 이걸로 도움받았다" 서사를 사용자가 직접 퍼뜨리게.
- [ ] **인앱 리뷰 요청** — ASO 1순위. 좋은 분석 결과를 본 직후 `SKStoreReviewController`/Play In-App Review로 초기 리뷰 확보.
- [ ] **발달단계별 홈/콘텐츠** — 분석에만 월령을 쓰는 현재를 넘어, 홈에 단계별 팁·체크리스트 노출 → 분석 안 해도 매일 열 이유(리텐션).
- [ ] **추세/성장 뷰** — 누적 분석으로 톤·패턴 변화 시각화. "도움받고 있다"는 체감 = 리텐션·후기 소재. (현재 스코프 제외 → 재포함 검토)

### P2 — 신뢰·차별화 (있으면 전환율↑)

- [ ] **전문가 감수 배지 / 코칭 근거 표기** — 육아는 신뢰가 전부. "발달심리 전문가 감수", 코칭에 근거 한 줄. 조작 후기보다 강력.
- [ ] **오디오 즉시 삭제를 트러스트 포인트로 노출** — 이미 삭제하고 있음. 온보딩·결과 화면에 "녹음은 분석 후 즉시 삭제됩니다" 명시 → 민감한 부모 안심.
- [ ] **추천/초대(referral)** — 맘 네트워크는 추천이 구매로 직결. 초대 보상 구조.
- [ ] **네이버 로그인** — 한국 타겟이면 가치(현재 제외). 우선순위 낮음.

## 2. 수익화 결정 (먼저 정해야 위 P0/P1이 구체화됨)

AI 분석은 건당 과금이라 **무료 무제한은 불가**. 셋 중 택1을 먼저 결정:

| 모델 | 설명 | 함의 |
|------|------|------|
| **프리미엄(구독)** 추천 | 월 N회 무료 + 무제한 구독 | IAP(StoreKit/Play Billing) 필요, 한국 결제·세금 |
| 횟수권(소비성 IAP) | 분석 N회 패키지 구매 | IAP 필요 |
| 완전 무료(초기 한정) | 베타·초기 트래픽 확보용 | 비용 한도 필수, 추후 전환 설계 |

> 결정에 따라 **인앱 결제 구현 + 사업자등록 + 통신판매업 신고**(한국 유료앱) 여부가 갈림.

## 3. 앞으로 해야 할 일 — 운영/계정/법무 체크리스트

### 개발자 계정 (리드타임 있음 → 먼저 착수)
- [ ] **Apple Developer Program 가입** ($99/년). 개인 vs 사업자 결정 — **사업자(조직) 계정은 D-U-N-S 번호 필요**(발급에 수일~수주). 개인 계정이 빠름.
- [ ] **Google Play Console** 등록 ($25 1회).

### 인프라/운영
- [ ] 도메인 구입 + 상시 백엔드(맥미니 named cloudflare tunnel 또는 클라우드 VPS/PaaS) + HTTPS.
- [ ] 프로덕션 DB: `synchronize:false` + 마이그레이션, 백업. CORS를 실제 도메인으로 제한.
- [ ] 시크릿 관리(OPENAI/ANTHROPIC/JWT/OAuth 키) — `.env` 노출 금지, 서버 환경변수/시크릿 매니저.
- [ ] OAuth 프로덕션 설정: Google/Kakao/(Apple) 실제 클라이언트 ID·리다이렉트·콘솔 심사.
- [ ] (푸시 시) APNs Auth Key + FCM 프로젝트.

### 법무/정책 (앱 심사 필수 항목)
- [ ] **개인정보처리방침 + 이용약관** 작성 후 공개 URL(앱·스토어에 링크).
- [ ] App Store **App Privacy(데이터 수집 영양표시)** 작성 — 음성/아동 정보 수집·삭제 명시.
- [ ] (유료화 시) 사업자등록 + 통신판매업 신고.
- [ ] 음성·아동 데이터 처리 고지(녹음 동의, 즉시 삭제 정책 문서화).

### 스토어 등록 자산 (ASO = 전략 1순위 준비물)
- [ ] App Store Connect / Play Console 앱 레코드 생성 (Bundle ID `com.prettyfour.prettyFour` 사용).
- [ ] 앱 아이콘(있음), **기기별 스크린샷**, 프로모 텍스트.
- [ ] **ASO 키워드/설명** — "육아 코칭", "훈육", "수면교육", "떼쓰기", 월령 키워드 등 부모가 검색하는 단어.
- [ ] 카테고리(교육/라이프스타일), 연령 등급.

### 베타 → 초기 리뷰 (전략 "ASO+초기 리뷰" 실행)
- [ ] **TestFlight**(iOS)/내부 테스트(Android)로 육아맘 베타 그룹 모집 → 피드백 + 초기 리뷰 확보.

## 4. 추천 실행 순서 (전략의 단계와 정렬)

```
[1단계: 출시 가능 상태 만들기 — 4~6주]
  운영 인프라 프로덕션화 · Apple Developer 가입(병행) · Sign in with Apple
  · 계정 삭제 · 개인정보처리방침/약관 · AI 비용 한도 · 애널리틱스 심기
  · 수익화 모델 결정(+필요시 IAP)

[2단계: 스토어 + 베타 — 2~3주]
  스토어 자산/ASO 작성 · TestFlight 베타(육아맘) → 초기 리뷰 확보

[3단계: 리텐션·바이럴 기능 — 출시와 병행/직후]
  발달단계별 푸시 · 결과 공유 카드 · 인앱 리뷰 요청 · 단계별 홈 콘텐츠
  (→ 인스타 마이크로 인플루언서 + 메타 소액광고 반응 테스트의 전환·측정 기반)

[4단계: 신뢰·확산 강화]
  전문가 감수 배지 · 추세 그래프 · 추천 초대 (→ 맘카페 후기형 바이럴 확산)
```

> **순서의 핵심:** 애널리틱스·공유·푸시가 없으면 마케팅을 "감"으로 하게 됩니다. 광고/인플루언서에 돈 쓰기 **전에** 측정(애널리틱스)·확산(공유)·리텐션(푸시) 3종을 깔아두면 같은 예산으로 몇 배 효율이 납니다.

## 5. 비용·리스크 메모
- **AI 변동비**: Whisper 분당 ~$0.006 + Claude 토큰. 유입 증가 = 비용 증가 → 요금제/한도 없으면 적자.
- **퀵터널 의존**: 현재 구조는 데모용. 마케팅 트래픽을 못 받음 → 1단계에서 반드시 해소.
- **민감 데이터**: 아동 음성. 신뢰가 마케팅 자산이자 리스크. 삭제 정책·보안을 마케팅 포인트로 전환.
- **심사 리젝 리스크**: Sign in with Apple 누락 / 계정 삭제 누락 / 개인정보처리방침 누락이 3대 단골 리젝 사유 — 1단계에서 선제 해소.
